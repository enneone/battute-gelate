# Battute Gelate

Template e contenuti della pagina Instagram @battutegelate.

- `templates/` — template HTML animati dei format (Reel, caroselli, post) e brand (colori, font, mascotte Gelo)
- `contenuti.json` — battute, hook e didascalie di ogni contenuto
- `render.py` — genera i Reel MP4 e le grafiche PNG (`python3 render.py reel`, `python3 render.py grafiche`)
- `output/` — file pronti da pubblicare, scaricati da Metricool tramite link pubblico
